# eval/results (개발용 표본 11건)

- `r1`, `r2`, `r3`: 도구를 같은 표본에 세 번 돌린 원래 AI 출력. 3회 일치율을 재는 데 쓴다.
- `r1b`: 프롬프트 변형 비교. `s1`: 1단계(근거 찾기)만 돌린 결과.
- `*c`: 판정 규칙을 고친 뒤 저장된 AI 출력으로 다시 채점한 것(AI 호출 없음). `report_dev.md` 8장의 v1, v2 수정.
- `r1fix`~`r1fix4`: 시험용 표본에서 드러난 결함(시간 범위 끝 시각, 나이 범위 등)을 고친 뒤 개발용 표본 77칸이 바뀌지 않는지 확인한 재판정.
- `baseline_*`: 비교군(같은 모델에 한 번 묻기, 정규식 규칙만). `baseline_chat_reading.json`은 Claude가 자유 답을 읽고 적은 판정.
- `smoke.json`: 처음 동작 확인용.
